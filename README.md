# Instagram Downloader Bot

Бот приймає в чаті посилання на пост / каруселю / рілс / сторіз з Instagram
і одразу присилає весь контент назад. Можна додати в будь-яку кількість
групових чатів (наприклад окремий чат для збору "сторітейлінгу" і "прогрівів").

## Локальний запуск (щоб протестувати)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впиши BOT_TOKEN (взяти в @BotFather), за потреби IG_USERNAME/IG_PASSWORD

export $(cat .env | xargs)
python3 bot.py
```

Додай бота в потрібні чати — він працює однаково і в особистих, і в групових.

## Токен бота

1. Напиши @BotFather в телеграмі
2. `/newbot`, вибери ім'я
3. Скопіюй токен — це і є `BOT_TOKEN`

## Розгортання (щоб працював 24/7, а не тільки поки увімкнений твій ноутбук)

### Варіант 1 — Render (найпростіше, безкоштовно, без картки)

1. Заливаєш цю папку на GitHub (окремий репозиторій)
2. На render.com → New → Background Worker (не Web Service — боту не потрібен HTTP)
3. Підключаєш репозиторій
4. Build command: `pip install -r requirements.txt`
5. Start command: `python3 bot.py`
6. В Environment додаєш `BOT_TOKEN` (і за потреби `IG_USERNAME`/`IG_PASSWORD`)
7. Deploy

Нюанс: free-план Render може "засинати" без активності — перше повідомлення
після паузи прийде із затримкою секунд 30-50, далі бот працює швидко.
Background Worker (на відміну від Web Service) не спить від неактивності
сайту, бо це не сайт — але акаунт все одно на free-лімітах по годинах,
для одного бота з помірним навантаженням цього більш ніж достатньо.

### Варіант 2 — Oracle Cloud Always Free VPS (більше на старті, зате справді назавжди безкоштовно і без затримок)

1. Реєструєш Oracle Cloud акаунт (потрібна картка для верифікації, гроші не знімають — always free tier)
2. Створюєш VM (ARM Ampere, 4 CPU / 24GB RAM, безкоштовний назавжди — з запасом на кілька ботів одразу)
3. Підключаєшся по SSH, ставиш python3, git
4. Клонуєш репозиторій, `pip install -r requirements.txt`
5. Щоб бот працював постійно, навіть після перезавантаження сервера — запускаєш через systemd або просто `screen`/`tmux`

Це трохи більше налаштування руками, зате це реальний, а не тимчасовий
безкоштовний хостинг — і на той самий сервер потім можна докинути й інших
ботів (наприклад для SendPulse-автоматизацій).

## Важливо про сторіз

Пости, каруселі й рілси бот качає без жодного логіну — просто через
посилання. А от сторіз Instagram без авторизації не віддає нікому, тому
для них потрібен `IG_USERNAME`/`IG_PASSWORD` окремого (не основного) акаунта.
Instagram не любить автоматизоване скачування і може обмежити такий акаунт —
тому це свідомий трейд-оф, не баг.

## Юридичний момент

Instagram у правилах користування забороняє масове автоматизоване
скачування чужого контенту. Для власного контенту, контенту з дозволом
авторів, чи для внутрішнього аналізу конкурентів командою це зазвичай
некритично на практиці, але варто розуміти, що технічно це порушення ToS
Instagram, а не закону — і акаунт, задіяний для сторіз, може під це
потрапити першим.
